What is commit history?

Git records snapshots of your project as commits. Commit history helps you see what changed, who changed it, and when.

$ git log --oneline

Example output:

a1b2c3dUpdate README
e4f5g6hAdd homepage
i7j8k9lInitial commit

Important commands

View history

git log --oneline

Shows a compact list of commits.

Check changes

git status

Shows modified, staged, and untracked files.

Soft reset

git reset --soft HEAD~1

Moves HEAD back one commit and keeps changes staged.

Mixed reset

git reset --mixed HEAD~1

Moves HEAD back one commit and keeps changes in your working directory, unstaged.

Hard reset

git reset --hard HEAD~1

Warning: Discards tracked working-tree changes. Use only when you are sure.

Undo safely

git revert <commit-id>

Creates a new commit that reverses an earlier commit.

Which reset should I use?

CommandCommit removed?Changes kept?
--softYes, locallyStaged
--mixedYes, locallyUnstaged
--hardYes, locallyTracked changes discarded
git revertNoCreates a reversing commit

Safe workflow

  1. Run git status to check your current changes.
  2. Run git log --oneline to inspect recent commits.
  3. If needed, create a backup branch: git branch backup-before-reset.
  4. Choose reset for local history changes or revert to undo a shared commit safely.
  5. Check the result with git status and git log --oneline.
